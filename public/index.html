RouterOS DDNS

让 MikroTik RouterOS 路由器在公网 IP 变化时，自动更新你的域名解析。支持 IPv4 与 IPv6，无需在路由器上处理 API 签名。

阿里云 DNS 阿里云 ESA 腾讯云 DNSPod

工作原理

路由器上的脚本定时比较当前公网 IP 与域名解析结果。只有两者不一致时，才会把域名和 API 密钥提交到本服务，由本服务调用 DNS 服务商的接口更新解析记录。

本服务不保存你的 Access Secret。

脚本下载

IPv4 DDNS 读取 WAN 接口地址；如果是内网地址（光猫拨号等情况），会自动获取真实公网 IP。
下载 ddns.rsc
IPv6 DDNS（路由器） 把 WAN 接口上的公网 IPv6 地址更新到域名。
下载 ddnsv6.rsc
IPv6 DDNS（局域网设备） 按 MAC 地址找到局域网内某台电脑的公网 IPv6 地址，并更新到域名。
下载 ddnsv6-for-pc.rsc

使用方法

  1. 在 DNS 服务商处先手动添加一条 A（IPv4）或 AAAA（IPv6）记录，值可以随便填。
  2. 创建 API 密钥（Access ID / Access Secret）。
  3. 打开下载的脚本，填写顶部的域名、接口名、service 和密钥。
  4. 在 RouterOS 的 System → Scripts 中新建脚本，粘贴内容。
  5. 在 System → Scheduler 中添加定时任务运行该脚本，例如每 10 分钟一次。

安全建议

建议为 DDNS 单独创建 RAM 子账号（阿里云）或子用户（腾讯云），只授予 DNS 解析的管理权限，不要使用主账号密钥。
